# Mods

Patchbay mods. On Patchbay's Mods page, click **Add Mod…** and choose the zip, then tick the mod.

| Mod | What it does | Download |
|---|---|---|
| [bo Master](bo-master) | The master track's strip beside Bitwig's browser | [bo-master.zip](https://github.com/bo3k/bo-bitwig/releases/latest/download/bo-master.zip) + [panels-framework.zip](https://github.com/bo3k/bo-bitwig/releases/latest/download/panels-framework.zip) |
| [Save Incrementally](save-incrementally) | Saves the next numbered version of the project | [save-incrementally.zip](https://github.com/bo3k/bo-bitwig/releases/latest/download/save-incrementally.zip) |
| [Insert Device via Shortcut](insert-device-via-shortcut) | Shortcuts for inserting devices | [insert-device-via-shortcut.zip](https://github.com/bo3k/bo-bitwig/releases/latest/download/insert-device-via-shortcut.zip) |
| [Panels framework](panels-framework) | Needed by bo Master: shaboogen's framework, with views beside the browser | [panels-framework.zip](https://github.com/bo3k/bo-bitwig/releases/latest/download/panels-framework.zip) |
